# Getting help

- **Install a port:** each repository's README has installation steps, and
  [living-code.dev/ports](https://living-code.dev/ports/) lists every port with previews.
- **Something looks wrong in one app:** open an issue in that port's repository using **Report a problem**. Include
  the app version, the flavor and a screenshot.
- **A color is wrong everywhere:** send [palette or color feedback](https://github.com/living-code-theme/core/issues/new?template=color-feedback.yml) to core.
- **Your app has no port:** [request a port](https://github.com/living-code-theme/core/issues/new?template=port-request.yml).
- **Anything else:** [help@living-code.dev](mailto:help@living-code.dev).
