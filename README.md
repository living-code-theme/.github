# living-code-theme/.github

Default community files for every repository in [living-code-theme](https://github.com/living-code-theme).

GitHub uses these defaults in any repository that has no file of its own: `ISSUE_TEMPLATE/`, the
pull request template, `CODE_OF_CONDUCT.md`, `SECURITY.md` and `SUPPORT.md`. Every port therefore gets the
same **Report a problem** form, plus links to request a new port or give palette feedback in
[core](https://github.com/living-code-theme/core), which has its own forms.

`profile/README.md` is the organization's public profile on [github.com/living-code-theme](https://github.com/living-code-theme).
It is generated by `scripts/profile.mjs` from the website's published port snapshot
([landing/data/ports.json](https://github.com/living-code-theme/landing/blob/main/data/ports.json)), so its port directory
lists exactly what [living-code.dev](https://living-code.dev/ports/) publishes. The `profile` workflow regenerates it daily
after landing's port sync and commits only when it changed. Edit the script, not the generated file.
