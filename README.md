# living-code-theme/.github

Default community files for every repository in [living-code-theme](https://github.com/living-code-theme).

GitHub uses `ISSUE_TEMPLATE/` in any repository that has no issue templates of its own. Every port therefore gets the
same **Report a problem** form, plus links to request a new port or give palette feedback in
[core](https://github.com/living-code-theme/core), which has its own forms.

`profile/README.md` is the organization's public profile on [github.com/living-code-theme](https://github.com/living-code-theme). Its port directory
mirrors each repository's `port.json` (group, emoji and name); update it when a port is added or renamed.
